现在 AI 岗拉开差距的关键，不是概念，而是项目

很多人都在学 Agent、LangGraph、混合 RAG、知识图谱、记忆机制。 但真正到了简历和面试环节，拉开差距的，往往不是你知道多少概念，而是：

  • 有没有做过相对完整的项目
  • 项目能不能跑起来、展示出来
  • 能不能把设计思路和技术亮点讲清楚
  • 面对深挖时，能不能接得住

尤其是 AI 应用开发、大模型应用开发这类岗位，面试官更看重的，通常是你的系统设计能力、工程落地经验和项目表达能力。

所以这次没有再做零散知识点整理，而是专门打磨了两套更适合求职、面试简历和项目展示的完整工程项目。

三套核心项目

  • CloudAgent 智能客服助手
  • DeepResearch 多 Agent 行业深度研究助手
  • 企业知识库RAG Agent工作台/知识库助手

这两套项目不是只能演示几分钟的简单 Demo，也不是把几个流行概念拼在一起，而是围绕真实业务场景设计出来的完整项目。

你既可以拿它们来系统学习 Agent 应用开发，也可以直接用于项目展示、简历表达和面试准备。基础介绍如下，具体项目效果往后滑

先跟大家说清楚，这套内容能提供什么：

  • 提供完整的前后端源码和项目文档，方便本地运行、学习和演示；
  • 项目不是零散知识点拼接，而是围绕智能客服、深度调研、企业RAG助手等核心业务场景设计的完整工程案例；
  • 除了代码本身，还会拆解项目中的设计思路、关键链路、优化方式和常见问题，帮助你理解项目为什么这样做；

项目介绍

1️⃣ DeepResearch 多 Agent 行业深度研究助手

在很多研究、分析、行业调研场景里，最大的痛点不是“写不出文字”，而是：

  • 信息来源分散
  • 资料查找耗时
  • 内容容易遗漏
  • 生成结果容易出现幻觉
  • 很难保证结论有依据、可核查

DeepResearch 这个项目，就是围绕这些问题设计的一套多 Agent 深度调研系统。 用户输入一个研究主题后，系统可以围绕任务拆解、信息搜索、证据筛选、内容分析、报告写作等环节逐步推进，最终输出带有来源依据的完整调研结果。

核心亮点：

  • 基于 LangGraph + ResearchState 实现多 Agent 编排，将 Intent Router、Planner、Web Scout、Local Scout、Evidence Judge、Analyst、Writer 解耦，形成可维护的节点化执行链路。
  • 构建 Bocha Web Search + Milvus RAG 的双路检索，并行召回外部信息与本地知识，提升证据覆盖率，降低单源信息偏差。
  • 通过 规则引擎 + LLM 意图识别 做路由分流，在保证质量的同时控制时延与 Token 成本。
  • 在证据处理环节引入 Evidence Judge（相关性过滤、去重、冲突检测、信源标注），把“可检索”提升为“可用证据”，增强结果可靠性。
  • 设计 Reflect 反思补搜机制 + 迭代控制，当证据不足时自动生成补充查询并二次检索，实现“检索-分析-补搜”的闭环优化。
  • 输出阶段强调 引用约束与溯源校验，通过来源编号与校验策略抑制幻觉引用，提升报告可核查性与可追溯性。
  • 实现 短期记忆（会话）+ 长期记忆（用户）+ 向量语义记忆（Milvus） 的分层记忆体系，支持跨轮次上下文注入与个性化应答。
  • 后端使用 FastAPI + SSE 输出节点级阶段事件，前端基于 Vue3 实时展示执行过程，提升可观测性与调试效率。
  • 支持 CLI + Web 双入口，形成从算法编排、服务接口到可视化交互的完整工程链路，便于演示和持续迭代。

2️⃣ CloudAgent 智能客服助手 —— 多 Agent 协同服务平台

在客服场景里，很多系统都存在类似问题：

  • 简单问题也要走完整推理链路，响应慢、成本高
  • 不同业务问题混在一起，处理链路混乱
  • 用户问题涉及订单、产品、规则等多个维度时，单一 Agent 很难稳定处理
  • 缺少检索、缓存、工具调用、安全权限等企业场景必须考虑的能力

CloudAgent 就是围绕企业级客服场景设计的一套多 Agent 协同服务平台。 它不是简单问答，而是从真实客服业务出发，考虑了问题路由、缓存、检索、图谱、工具调用、权限控制、记忆和流式展示等一整套能力。

核心亮点：

  • 基于 LangGraph + AgentState 构建状态机路由多Agent协同编排，覆盖Orchestrator、Product、Billing、Recommend、FinOps 多个Agent
  • 在 FastAPI 网关层前置 Milvus 向量查询，构建 L1/L2 双层语义缓存，拦截高频标准问题，首字响应缩至 80ms，节省token
  • 构建 Milvus (长文本) + Neo4j (图谱) 的混合检索（Hybrid RAG），并行召回模糊概念与精确规格数据，减少复杂云架构选型场景下的参数“幻觉”。
  • 采用 FastMCP 协议重构底层服务调用，将查库、调外网 API 等异构能力标准化为独立 Server，封装为MCP工具进行调用
  • 设计具拦截器，在 LangGraph 节点流转底层绑定当前登录用户 ID，防止Prompt 注入导致的越权查库攻击。
  • 实现 Redis 滑动窗口 (短期) + Milvus 向量化提取 (长期) 的分层记忆体系，会话前自动融合记忆注入 Orchestrator 路由，支持长周期复杂对话中的跨会话认知与个性化应答。
  • 后端使用 FastAPI + SSE 输出流式图状态，前端基于 Vue3 实时渲染多 Agent 协同的中间阶段与思考过程，全面提升复杂决策链的可观测性与调试效率。

3️⃣ AI应用开发项目实战知识库 - 企业知识库RAG Agent工作台/知识库助手【全栈AI项目】

在很多企业知识管理、文档问答、内部知识助手场景里，最大的痛点不是“大模型不会回答”，而是：

  • 文档来源复杂，格式不统一
  • 表格、图片、扫描件类内容很难稳定解析
  • 只做向量检索时，标题词、字段名、课程名这类问题命中不稳
  • 回答结果缺少来源依据，出了问题很难排查
  • 从入库、检索到问答的链路割裂，缺少完整调试与观测能力

这个项目，就是围绕这些问题设计的一套 企业级知识库 RAG Agent 工作台 。 用户上传文档后，系统会围绕文档解析、OCR 路由、结构化切分、向量入库、混合检索、证据注入、Agent 问答、来源溯源等环节逐步推进，最终输出带有来源依据的回答结果，并支持前端对文档、Chunk、检索结果和对话链路进行可视化观测。

核心亮点：

  • 基于 Document -> Section -> Chunk -> Vector 的分层知识管理设计，将文档主数据、切分块、向量副本解耦，形成可维护、可编辑、可重建的知识库链路。
  • 构建 原生解析 + OCR 智能识别 的双链路文档处理机制，针对 PDF、Docx、Markdown、TXT 等多类型文档统一接入，并结合表格数、图片数、文本密度等启发式规则动态选择解析路径，提升复杂文档可用入库率。
  • 在切分阶段实现 半结构化保护式切分策略 ，对 OCR 返回的 <table> 、 <img> 等 HTML 块进行保护，降低表格碎片化与结构丢失问题，把“能解析”提升为“能稳定参与检索与问答”。
  • 构建 Milvus 向量检索 + 应用层 BM25 + RRF 融合排序 的混合检索体系，并行召回语义相关内容与关键词精确内容，提升标题词、字段名、课程名、表格字段等场景下的综合命中效果。
  • 在问答阶段引入 Prefetch 预检索机制 ，在模型生成前先完成知识库证据检索，并将高相关来源片段注入上下文，增强回答稳定性，降低 Agent 绕开知识库直接生成的风险。
  • 基于 LangChain / LangGraph 构建 Agent 对话链路，结合工具调用与会话线程机制，实现多轮对话、流式回答和来源延续，形成可扩展的 Agent 工程骨架。
  • 输出阶段强调 来源溯源与证据可解释性 ，系统返回的不只是最终答案，还会同步回传命中的 chunk_id 、文件名、页码、检索来源、向量分、BM25 分和融合分，提升结果可核查性与调优效率。
  • 后端通过 FastAPI + SSE 输出流式回答与阶段事件，前端基于 Vue3 搭建文档管理、Chunk 观测、检索调试、Agent 对话与历史会话工作台，形成从算法链路到可视化交互的完整工程闭环。
  • 支持 Chunk 编辑、Chunk 删除、文档级物理删除、索引重建、问答日志落库 等知识库运维能力，让系统不仅“能回答”，还能“能管理、能调试、能持续迭代”。

4️⃣ 基于DeepAgent与Harness的多智能体可信数据分析平台 ｜ DataSherlock Nexus

项目亮点

  • 构建数据分析 Agent Harness 控制中枢，统一治理智能体的规划、权限、预算、执行、验证、恢复与审计。
  • 基于 LangGraph + 类型化状态编排多 Agent 工作流，实现节点级状态追踪、任务路由、Checkpoint 持久化与断点恢复。
  • 融合 Deep Agents 多专家规划机制，由业务诊断、量化设计与证据审查 Agent 协同生成结构化调查计划。
  • 通过任务 DAG、角色/工具白名单、预算守卫与独立工作区，为 Agent 建立可控、可追溯的运行边界。
  • 构建“注册工具 + 动态代码生成”双执行引擎，自动适配普通表格、宽表跨列、跨 Sheet 与自定义指标计算。
  • 实现代码级自愈机制，打通“代码生成—受限执行—结果验证—错误反馈—自动重写”闭环，失败任务最多自主修复三轮。
  • 通过 AST 安全检查、危险调用拦截、独立 Python 进程与超时控制，为 AI 生成代码提供受限沙箱执行环境。
  • 引入 Evidence Gate 证据门禁，从数据来源、字段类型、覆盖范围、质量风险与结论充分性多维评审证据，报告仅使用通过验证的计算结果。
  • 设计 Critic 驱动的调查自愈机制，证据不足时自动生成 Challenge、补充分析任务并重新执行验证。
  • 实现运行状态、会话上下文与用户长期经验的分层记忆，将已验证的分析经验沉淀并复用于后续任务规划。
  • 接入 LangSmith Agent 调用链路监控，观测模型调用、工具执行、节点输入输出、耗时与异常，并结合本地事件和产物完成审计。
  • 提供 FastAPI + Vue 3 可视化工作台，实时展示多 Agent 协作、动态代码、自愈过程、证据等级与最终分析报告。

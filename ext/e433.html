AI Reflection

围绕 agent 系统、模型能力、应用落地的技术反思。 话题由 AI 助手搜集整理（早期用 Claude Code、现在也用 DeepSeek Harness），每次给我 6-7 个选项，我挑一个展开对谈，最后由它整理成对谈稿。 每周 2-3 篇,质量优先。

对谈

  • 2026-11-17 · 单价、档位、每任务成本，三层都不可比：榜单在企业里不是选型工具 — 三层都不可比；榜单在企业里是议价材料，企业真正的成本是切换成本
  • 2026-11-13 · 决策模型不缺模型，缺一张判定表 — 它不缺模型，缺一张人画的判定表；判定层的天花板不是模型，是手柄太少
  • 2026-11-10 · benchmark 不是被人刷坏的，是被可测性拽歪的 — 被刷坏不是意外，是「只能测这个」的必然；新鲜卖判别力，陈旧卖校准
  • 2026-11-05 · 上下文该给「可推翻的过去」，不是「可依赖的过去」 — 压缩的时机该由结果决定，不由长度决定；状态存结论必然被抄，存证据才推得翻
  • 2026-11-04 · 机制无懈可击的修正，收益全在误差棒里 — MTP 梯度里 80% 是低信噪比残差，剔掉它机制上无懈可击，可观测收益却都落在噪声带里
  • 2026-10-27 · 共享必须是你要的，不能是你不小心得到的 — 隔离不用拿性能换；它漏在共享，烂在通报到不了算子手上
  • 2026-10-23 · 我看到了自己的织布机 — 入行十年的一次长篇对谈：十年里我一直待在同一根替代链上，只是这次轮到了自己
  • 2026-10-21 · 被留下的那一半，才是护城河的位置 — 开源送出的是问题排序；护城河是「负担得起做实验」，不是设计知识
  • 2026-10-19 · 你的 decode 账单，六七成是在为「把想法说出来」付费 — 省下的不是算力，是「说出口」的税；而这笔税和 effort 压缩抢的是同一块地
  • 2026-10-12 · 自学习缺的不是数据，是「对照」：可靠信号都粗，细的信号都不可信 — 判决信号要同时可靠且指到决策层；干净 outcome 让经验在一条样本就饱和，脏 outcome 则把错标当教材
  • 2026-10-08 · Haiku 5.5 的降价是分段定价：便宜档认输，agent 档加价 — 便宜档认输跟价，agent 档加价卖能力；10 万 token 那道坎是分段线，不是定价失误
  • 2026-09-28 · 推理效率提升不是均匀的：上限没动，省下来的钱主要在下限 — 省下的是便宜题，难题长度基本没动，而难题才是花钱的大头
  • 2026-09-22 · 骨干一行没改，53 分全在后训练——但数据与算法的账没人拆 — 架构一行没改，增益全在后训练；但数据还是算法的账，没人拆
  • 2026-09-20 · 01 型判断值钱,但决策模型的天花板是串行深度 — 决策模型换掉的不是 CoT,是串行深度;它把推理搬进了你的代码
  • 2026-09-14 · LLM serving 是个盲盒 — 同权重不同 serving 栈能差 20 个点,而验证它的路目前只有一条
  • 2026-09-11 · Effort 档位不死,只是换主人:终局不是自决,是定价学 — 选择权上移 harness 而非模型自决,档位终被产品吸收成定价旋钮
  • 2026-09-03 · 模型是耗材，失败模式知识才是资产 — checkpoint 是耗材，验证过的场景数据才是复利资产
  • 2026-08-31 · harness 自进化撞两堵墙:信号粒度锁上限,补偿机制按月折旧 — 模块级决策要模块级信号喂;承重在模型缺陷上的补偿机制按模型升级节奏折旧
  • 2026-08-26 · thinking 是计算,不是内容:把 thinking 预算拆成三份 — 拆成内容/冗余计算/唯一计算三份,effort 压缩、收敛即停、蒸馏各砍一段
  • 2026-08-24 · Harness 不会溶解成「注意力接口」，它在跟模型互相拉升 — 删 80% 提示词是删债不是吸收;interface 层收敛,capability 层扩张
  • 2026-08-21 · Effort 档位终将消失：它是成本方差的拐杖，不是质量开关 — 档位的真实功能是控制成本方差;终局是模型自决 CoT 长度
  • 2026-08-19 · 模型分流是过渡态，统一架构才是终态 — 分流是工程债的利息;真难点在升级信号从哪来,不在判别器多准
  • 2026-08-17 · 品味是护城河，别把它写成清单 — 品味=延时反馈的当下代理;量化品味等于杀护城河,该内部量化不写清单
  • 2026-08-13 · 加密思维链守不住护城河 — 藏 CoT 守得住安全合规,守不住能力领先;数据边界=谁当 endpoint 谁拿全文
  • 2026-08-12 · 文本水印是合规义务,不是检测方案 — 技术有效边界极窄,做不了「是不是 AI」的检测;真实功能是合规义务+品牌归因
  • 2026-08-10 · 记忆防不住,就不该严防:分型止于认识论,门控落在动作层 — 写入时打后果类型做不到干净;门控上移到动作层,修正回路由存储层承运
  • 2026-08-05 · 长程 harness 的承重墙是环境反馈，不是角色分离 — 把环境反馈从模型查改成环境编程式吐 delta,轻骨干反而更通用
  • 2026-08-03 · agent 安全的着力点不在模型——在工具面、在保单、按 regime 分层落 — 防守是市场失灵不是稳态军备竞赛;真正的 forcing 是保险不是法律
  • 2026-07-31 · BM25 不是复古,是通用 embedding 时代的廉价 precision 保险 — 真正的问题是 hybrid 里 BM25 的动态加权,不是静态范式选型
  • 2026-07-27 · 推理努力度控制不会涌现,快慢分流的触发才是落地的承重点 — 元认知信号不会免费涌现,得专门训;分流要拆开能力信号和产品策略两条轴
  • 2026-07-24 · eval 的难度，继承的是产品的难度 — grader 难做恰恰是护城河所在;eval 没有独立身份
  • 2026-07-20 · 提示词不会变成代码,check 会搬到运行期 — check 的发生位置会从开发期挪到运行期(trace + 事后审计)
  • 2026-07-16 · 跨范式混栈贵不贵,看边界是序列化的还是流式的 — 耦合税正比于边界上活 context 流的连续度;diffusion 只争序列化 node 一格
  • 2026-07-15 · 省力策略的甜区,是 spec 已经闭合的任务 — 「简单」被操作化成 spec-closed;换个分布收益从 91% 跌到 20% 以内
  • 2026-07-13 · 当 harness 焊进模型权重，评测就从机器学习走向产品了 — model-harness 耦合是数据分布物理规律;评测正从机器学习走向产品
  • 2026-07-10 · context 管理缺一个跨时间价值信号 — 该在 self-GC 之上挂显式行为价值层,不是搬统计后验
  • 2026-07-07 · 可形式化,才是 inference-time 控制的分水岭 — 分界不是强度,是属性可否形式化;约束解码占死可形式化半边
  • 2026-07-03 · Context 治理的难点不是容量,是认知在场权 — 删除不对称,认知治理必须保守;主线默认降权而非删除
  • 2026-06-30 · 并行 draft 是 NAT 老路重演：从 DSpark 看投机解码的 mask 困局 — 无损性约束比 mask 不一致更硬,卡死一票替代路线
  • 2026-06-26 · 把"AI 安全"拆开:概率层、价值判断与责任结构 — 真问题不是判断准确度,是责任结构;拒绝信号该结构化归因
  • 2026-06-24 · MCP 真正不可替代的,只剩 auth —— LLM 把工具集成那部分吃掉了 — 工具集成已被 LLM 吃掉,真正不可协议化的只剩 auth
  • 2026-06-23 · Agent 工业落地的拧巴是结构性的 —— 不是管理问题,是物理问题 — 速度/质量/能力上限在同一个 forward pass 抢算力,是物理问题不是管理问题
  • 2026-06-18 · Engram 是窗口期产物 —— 多模态压力会剥掉参数化记忆的差异化 — per-user memory 烧进参数是窗口期产物,多模态压力会剥掉差异化
  • 2026-06-15 · 工具空间该跟垂域复杂度匹配 —— 从 Fable 5 的"主动性拉满"说起 — agent 化带来垂域分化,不是产品同质化;收敛维度该从工具数量挪到垂域边界
  • 2026-05-29 · 80% 的 commit 来自 AI 没什么好震惊的——写 commit 本来就不是工程落地里最复杂的环节 — 沟通和共识是新瓶颈,AI 红利的乘数是用户判断力,不是 AI 能力本身
  • 2026-05-27 · 事件与模式:agent 记忆的两层结构,以及为什么模型不必长成人 — 把人做不到的几条轴(可审计、可移交、可修正)做透,比模仿人脑更稳
  • 2026-05-25 · 压缩和记忆应当是一体设计 —— 从并行上下文压缩说起 — 压缩该和记忆构造一起设计,schema 从未来检索方式反推
  • 2026-05-22 · 评测的代价权重该跟场景画像绑定 —— 从 π-Bench 拆 Proactivity 说起 — 下一步不是堆更多维度,是让维度权重跟应用场景绑定
  • 2026-05-21 · 关于 Mem-π:把"记忆写入"塞进 token 流,这条路应该走不远了 — 记忆该是 agent 工具箱里的工具,不是模型生成层面的决策

Obsidian 必装的 9 个 AI Agent Skill

2026-04-06 · 小红书 · 原文来源 ↗ · 工具与技术/20260406-Obsidian必装的9个AI-Agent-Skill.md

来源：小红书 归档日期：2026-04-06 抓取状态：成功 原文字符：1382｜配图：2 张

摘要速览

用 AI Agent（Claude Code / OpenCode）操作 Obsidian 时，不知道装哪些 Skill、怎么配置，盲目选择浪费 Token。这 9 个 Skill 覆盖了知识管理的核心场景：内容抓取、知识库操作、可视化、深度学习。

核心内容

一、Obsidian 官方 5 个 Skill

1. defuddle — 网页/视频转 Markdown

把网页、YouTube 视频等内容转成 Markdown 并保存到知识库。Obsidian 官方 Web Clipper 插件基于此工具。

npm install -g defuddle

安装后放入智能体文件夹。

2. Obsidian CLI — 从终端操作 Obsidian

官方最新工具，高效节省 Token。注意：OpenClaw 官方仓库中的旧项目已过时，建议用 ClawHub 官方市场的官方 Skill。

3. Obsidian Bases Skill — 编写 .base 格式的 yaml 文件

教 AI 创建复杂数据库（.base 格式），常结合 Obsidian CLI 做知识库架构级操作。

4. Obsidian Markdown Skill — 制定笔记撰写标准

为 AI 制定撰写 Obsidian 笔记的标准流程和格式。建议根据自己的格式偏好扩展。

5. JSON Canvas Skill — Canvas 白板架构展示

用于 Canvas 白板知识架构展示，但存在节点大小和文字显示问题，有更好的替代方案（见下）。

二、博主 Axton 的 3 个画图 Skill（替代官方 Canvas）

6. Canvas Skill — 优化节点坐标和布局

生成的 Canvas 思维导图无需手动调整节点。

7. Mermaid Skill — 生成清晰代码结构

生成的代码结构清晰，几乎无需手动调试。

8. Excalidraw Skill — 头脑风暴和深度思考

生成的图表结构完整，适合头脑风暴。Excalidraw 是 Obsidian 插件市场下载量排名第一的插件。

三、2 个深度知识学习 Skill

9a. Tutor Skill — 快速学习文档/代码项目

适合应对考试和面试。能生成：

  • 完整的 Obsidian 知识库
  • 双链 MOC 内容地图
  • 结构化标签
  • 测试和学习仪表盘

9b. Scholar Skill — 学术科研

具备记忆管理和长期任务编排能力。深度依赖 OpenClaw，消耗 Token 多，建议学术科研需求者使用。

四、Obsidian 智能体插件配置

Claudian 插件（Claude Code 专用）

  1. 先安装 Claude Code
  2. 通过 BRAT 插件添加 Beta plugin，或手动下载放入 plugins 文件夹
  3. 在设置中填写称呼、模型等信息
  4. 如果所在地区限制，需填写变量转接兼容模型

Obsidian-agent-client 插件（支持多种 AI Agent）

支持 Claude Code、Gemini、OpenCode 等。以 OpenCode 为例：

  1. 在 custom agent 中添加
  2. 设置 Agent ID、路径、参数等
  3. 完成后打开插件 AI 对话框即可使用

为什么有用

Obsidian 的核心价值在于"知识网络"，但手动维护双链、MOC、标签体系非常耗时。AI Agent + 这 9 个 Skill 能自动化大部分重复劳动：

  • 内容抓取（defuddle）
  • 知识库架构操作（Obsidian CLI + Bases）
  • 可视化（Canvas / Mermaid / Excalidraw）
  • 深度学习（Tutor / Scholar）

关键是选对 Skill，避免盲目安装浪费 Token。

具体步骤

  1. 先装 Obsidian CLI + Markdown Skill（基础操作）
  2. 根据需求选画图 Skill：思维导图用 Canvas，流程图用 Mermaid，头脑风暴用 Excalidraw
  3. 如果需要深度学习，装 Tutor Skill（快速学习）或 Scholar Skill（学术科研）
  4. 如果需要网页/视频抓取，装 defuddle
  5. 如果需要复杂数据库，装 Bases Skill
  6. 配置对应的 Obsidian 插件（Claudian 或 Obsidian-agent-client）

适用 / 不适用场景

  • 适用：用 Obsidian 做知识管理 + 用 AI Agent（Claude Code / OpenCode）的人
  • 适用：需要自动化知识库维护（双链、MOC、标签）的人
  • 适用：需要快速学习大量文档/代码的人（Tutor Skill）
  • 不适用：不用 Obsidian 的人
  • 不适用：不用 AI Agent 的人
  • 不适用：只用 Obsidian 做简单笔记、不需要复杂知识网络的人

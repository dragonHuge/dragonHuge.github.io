第三章： Claude Code 20个常用斜杠指令速查表

2026-11-09 · AI与大模型/大模型实战宝典/raw/15-04-第三章：Claude Code 20个常用斜杠指令速查表.md

Claude Code 20个常用斜杠指令速查表

序号指令功能说明
---
1/help查看所有内置指令、快捷键及使用帮助
2/clear清空当前对话上下文，重置会话，避免历史内容干扰
3/compact压缩总结对话历史，精简上下文，防止 token 超限
4/context查看当前会话 token 占用情况，分析文件上下文消耗
5/cost统计本次会话 token 消耗，查看预估调用费用
6/rewind回退上一轮所有代码修改与操作，快速恢复误改内容
7/btw 问题临时穿插提问，不打断当前开发任务、不污染上下文
8/model快速切换 Opus/Sonnet/Haiku 等可用模型
9/effort设置模型思考强度，简单任务选 low，复杂重构选 high
10/fast开启极速响应模式，适合小修改、查语法，提升回复速度
11/config打开全局设置面板，配置模型、文件权限、界面样式等
12/init新项目初始化，自动生成 CLAUDE.md 项目规则文件
13/memory编辑项目长期记忆，固定编码规范、业务规则无需重复说明
14/diff预览所有代码改动差异，核对修改内容
15/review对项目代码做评审，排查 bug、安全隐患、不规范写法
16/doctor诊断 Claude Code 环境、权限、网络类报错并给出修复方案
17/plan规划模式，先输出修改方案，确认后再改动代码，防止误操作
18/run自动执行项目运行、编译命令，验证代码修改效果
19/copy一键复制上一轮 AI 全部回复内容到剪贴板
20/export把当前对话导出为 Markdown 文件，用于存档复盘

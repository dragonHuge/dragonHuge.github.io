1 快速上手 —— 什么是 Claude Code

1.1 什么是 Claude Code

Claude Code 是一款面向普通用户的 AI 助手工具，如同「智能同事」，支持通过自然语言指令完成数据分析、文件整理、代码编写重构等各类开发任务。

非程序员友好特性

产品设计兼顾零基础用户，无需编程基础即可上手：

  • 自然语言交互：支持中文对话，沟通门槛低
  • 多操作载体：原生提供命令行工具，同时配套 JetBrains IDE 图形插件
  • 所见即所得：实时展示处理结果，无需记忆复杂命令

注意事项： 1. 国内安装若无网络代理，推荐使用国内 npm 镜像源安装； 2. 需确保已安装 Node.js 18.0 或更高版本； 3. 仅在 IDEA 中使用时，可跳过 1~4 步骤，直接安装 IDEA 插件。

命令行安装与配置（通用流程）

步骤 1：以管理员身份打开终端

Windows 系统打开 CMD 或 PowerShell，执行以下安装命令（指定淘宝 npm 镜像，提升国内下载速度）：

npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com

步骤 2：验证安装结果

执行以下命令，输出 Claude Code 版本号即安装成功：

claude --version

步骤 3：配置模型参数

通过 settings.json 配置使用的模型，文件默认路径：C:Users你的用户名.claudesettings.json。

创建并编辑配置文件（PowerShell 命令）：

mkdir $env:USERPROFILE\.claude -Force
notepad $env:USERPROFILE\.claude\settings.json

配置示例（国内大模型）：

  • Mimo 模型
  • {

"env": { "ANTHROPIC_BASE_URL": "https://api.xiaomimimo.com/anthropic", "ANTHROPIC_AUTH_TOKEN": "MIMO_API_KEY", "ANTHROPIC_MODEL": "mimo-v2.5-pro", "ANTHROPIC_DEFAULT_SONNET_MODEL": "mimo-v2.5-pro", "ANTHROPIC_DEFAULT_OPUS_MODEL": "mimo-v2.5-pro", "ANTHROPIC_DEFAULT_HAIKU_MODEL": "mimo-v2.5-pro" } }

  • DeepSeek 模型
  • {

"env": { "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic", "ANTHROPIC_AUTH_TOKEN": "你的 DeepSeek API Key", "API_TIMEOUT_MS": "600000", "ANTHROPIC_MODEL": "deepseek-v4-flash", "ANTHROPIC_SMALL_FAST_MODEL": "deepseek-v4-flash", "ANTHROPIC_DEFAULT_SONNET_MODEL": "deepseek-v4-flash", "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-v4-flash", "ANTHROPIC_DEFAULT_HAIKU_MODEL": "deepseek-v4-flash" } }

说明：不同大模型的配置可参考对应官方文档，直接复制适配即可。

步骤 4：验证模型

在 PowerShell 中输入以下命令，进入 Claude Code 初始化界面即代表模型配置生效：

claude

1.2 在 IntelliJ IDEA 安装 Claude Code 插件

前置准备

Claude Code JetBrains 插件依赖 Claude Code CLI，需先完成 CLI 安装：

macOS / Linux / WSL

curl -fsSL https://claude.ai/install.sh | bash

Mac 备选：Homebrew 安装

brew install claude-code

Windows 全局安装

npm install -g @anthropic-ai/claude-code

安装校验：执行 claude --version，输出版本号即 CLI 安装成功。

安装步骤

步骤 1：打开 IDEA 插件市场

两种入口任选其一：

  1. 菜单栏：文件 → 设置 → 插件（Plugins）
  2. 快捷键：
  • Windows：Ctrl+Alt+S
  • macOS：Cmd+,（进入设置面板后切换至 Marketplace 市场）

步骤 2：搜索并安装官方插件

在插件市场顶部搜索框输入 Claude Code，选择 Anthropic 官方认证插件，点击「安装」。

步骤 3：重启 IDE 生效

下载完成后，按弹窗提示重启 IDEA，插件自动生效。

1.3 IDEA 内 Claude Code 界面与基础操作

打开交互窗口

打开任意项目文件后，点击 IDEA 右侧工具栏的 Claude Code 对话气泡图标，唤起交互窗口。

账户配置（国内推荐）

路径：设置 → 供应商管理 → Claude Code，添加 API 密钥并保存，完成连通测试。

配置界面参考： ⚠️ 重要提示：Claude 官方服务国内网络访问受限，文档提供「国内大模型代理接入」方案，保障稳定使用。

基础快捷操作

在输入框输入 / 可唤起快捷菜单，支持：

  • 对话管理：新建会话、恢复历史对话、清空上下文
  • 文件操作：上传本地文件、指定项目代码路径作为上下文
  • 全局参数配置、快捷斜杠命令

1.4 IDEA 版 Claude Code 完整界面详解

插件聊天面板固定在 IDE 右侧，分为三大核心区域：

一、聊天窗口（核心交互区）

  1. 底部输入框
  • 支持多行输入、拖拽文件上传、粘贴代码
  • 快捷键：Enter 发送消息；Shift+Enter 换行
  1. 对话历史区
  • 完整保存问答记录，每条消息附带时间戳
  • 支持一键复制 AI 代码、单条消息删除
  1. 消息样式区分
  • 用户消息：右侧展示，附带本地头像
  • Claude AI 回复：左侧展示，带 AI 标识，代码块可一键插入项目
  • 系统提示：插件加载、鉴权、报错通知

二、对话核心操作

  • 发送指令：输入需求回车发送
  • 终止生成：AI 输出过程中，点击输入框「停止」中断输出
  • 代码应用：AI 代码块右上角「应用至文件」，支持覆盖原有代码 / 新增文件

三、快捷工具栏功能

  1. / 快捷菜单：对话管理、文件引用、全局配置入口
  2. @ 文件选择器：快速选中项目内任意代码文件作为上下文
  3. 思考模式开关：开启后 AI 输出完整推理过程
  4. 执行模式切换（输入框左下角）

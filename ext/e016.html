本文档聚焦 Claude Code 核心基础操作能力，涵盖对话交互、文件操作、文本生成三大核心场景，帮助用户快速掌握工具基础用法与高效使用技巧。

1.1 输入框基础操作

1.2 消息发送方式

  1. 输入完成后按下 Enter 直接发送
  2. 点击输入框右侧纸飞机样式的发送按钮发送

1.3 回复查看与等待

  • 发送后出现「正在思考…」提示，内容逐字流式输出，回复结束后提示消失（一般几秒内返回结果）
  • AI 回复展示在左侧对话区（带 AI 标识），支持纯文本、有序 / 无序列表、代码块、表格等格式，长内容可滚动查看

1.4 对话历史管理

  1. 查看历史：输入框上方展示全部对话记录，最新消息在最下方，每条消息带时间戳，可向上滚动回溯
  2. 接续对话：模型记忆上下文，可基于历史内容追问、延展话题、切换需求
  3. 清空对话：点击工具栏「新建对话」按钮，或在设置中清除历史，开启全新会话

2.6 实操示例（文件操作）

  1. 代码重构：@UserService.js 请帮我重构这个文件，使用 async/await 替代回调函数
  • 核心动作：回调改 async/await + 补充异常处理 + 优化结构 + 添加 JSDoc 注释
  1. 新增业务功能：@TodoList.jsx 请帮我添加一个删除待办事项的功能
  • 核心动作：新增删除函数 + 绑定删除按钮 + 二次确认弹窗 + 更新状态逻辑
  1. Bug 修复：@login.js 用户登录时总是失败，请帮我定位并修复问题
  • 常见问题：接口 URL 错误、异常捕获不完善、缺少超时容错
  1. 安全审查：@PaymentService.ts 请审查支付服务代码，排查潜在安全漏洞
  • 常见风险：敏感信息硬编码、入参未校验、金额无二次校验、异常暴露敏感信息
  1. 批量修改：@api/*.js 给所有 API 接口文件统一添加请求超时配置
  • 核心动作：设置默认超时 + 封装异常捕获 + 标准化错误返回

3. 基本文本生成

3.1 营销类文案生成

3.2 文本改写类

  • 文本润色：将口语化 / 平淡文字优化为流畅、有说服力的正式文案
  • 语气风格调整：支持口语、正式、幽默、文艺等风格切换
  • 文本精简压缩：剔除冗余，保留核心信息，简短清晰表达原意

3.3 文本总结与信息提取

  • 长文本总结：提炼核心观点、行业趋势、机遇挑战、未来展望（结构化输出）
  • 关键信息提取：从会议纪要 / 方案文档中提取任务负责人、工作内容、截止时间、会议安排等

4. 附：高效使用技巧与注意事项

4.1 通用高效技巧

  1. 提问 / 指令技巧：需求描述清晰具体，复杂问题补充背景，大问题拆分为小问题分步提问；结果不符时直接反馈，优质回复及时备份
  2. 文本生成技巧：补充详细细节、限定字数、明确文体风格、多次迭代优化、沉淀常用模板
  3. 文件操作技巧：
  • 用相对路径精准定位文件（避免重名混淆）：请帮我修改 ./src/utils/helpers.js 中的 formatDate 函数
  • 基于目录批量操作：请在 src/components 目录下新建一个 Card 通用组件
  • 模糊描述定位文件：帮我找到并修改处理用户登录逻辑的文件
  • 上下文连续对话：无需重复 @已操作过的文件，直接追问需求
  • 精准修改代码片段：@app.tsx 优化第45-60行的页面渲染逻辑

4.2 注意事项

  1. 路径规范：统一使用 / 作为分隔符，保证跨系统兼容
  2. 权限要求：确保终端工作目录对目标文件有读写权限
  3. 风险防控：批量大范围修改前备份代码，防止误改
  4. 范围限制：仅可操作当前打开工作区内的文件，无法访问项目外文件
  5. 超大文件处理：拆分分批处理，避免上下文超限、处理超时

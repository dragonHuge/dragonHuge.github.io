摘要速览

  • Agent benchmark = 智能体标准化考卷（SWE-bench / GAIA / τ-bench），需防 reward hacking 刷分。
  • Agent 范式：Auto Research 自主调研、Rehearse 预演、AutoSOTA 自动调优。
  • 训练路径：预训练 → SFT 刷题打底 → RL 奖励信号拔高。
  • Massive Activations 与 attention sink 相关，经历 write-sink-cancel 三阶段，可预测故可用于量化/剪枝优化。
  • Full Attention O(n²) 与线性注意力 O(n) 可混合，兼顾表达力与效率。

核心内容

  1. Agent benchmark：智能体标准化考卷，代表有 SWE-bench、GAIA、τ-bench，存在 reward hacking（刷分）风险需防范。
  2. Agent 范式：Auto Research（自主调研）、Rehearse（预演）、AutoSOTA（自动调优）。
  3. 训练路径：预训练 → SFT（刷题打底）→ RL（奖励信号拔高）。
  4. Massive Activations：与 attention sink 相关，经历 write → sink → cancel 三阶段，因其可预测性可用于量化/剪枝优化。
  5. 注意力复杂度：Full Attention O(n²) 与线性注意力 O(n) 可混合使用，兼顾表达力与效率。

可执行启发

  • 评测 Agent 时需意识到 benchmark 可被 reward hacking 刷分，应结合真实任务验证。
  • 优化推理效率时，可考虑混合 O(n²) 与 O(n) 注意力，并利用 Massive Activations 的可预测性做量化/剪枝。

第四章：文本处理与创作

2026-11-09 · AI与大模型/大模型实战宝典/raw/15-05-第四章：文本处理与创作.md

文案生成是 AI 常用功能，覆盖产品宣传、广告、社交内容等场景，可快速产出高质量文案。

产品描述创作

基本方法

生成产品描述需提供 3 类信息，输出效果更佳：

  • 产品名称和类型
  • 主要功能和特点
  • 目标用户群体

一、原基础提示词

请基于以下信息，为我撰写一份专业的产品宣传描述文案，用于产品推广、广告投放、社交媒体发布：
1. 产品名称与所属品类
2. 产品核心功能、差异化特点、优势亮点
3. 精准的目标用户人群画像
要求文案内容高质量、贴合推广场景，具备吸引力与说服力。

二、优化后多版本提示词

版本 1：专业标准版（电商 / 官网产品详情）
# 角色定位
你是资深产品营销文案师，擅长撰写电商详情、官网产品介绍类文案，语言专业严谨，突出产品价值，精准触达目标用户痛点。
# 输入信息
1. 产品名称+所属行业/产品品类
2. 产品核心功能、核心优势、差异化卖点、使用场景
3. 目标用户群体、用户痛点、用户核心需求
# 输出要求
1. 撰写800字以内产品宣传文案，结构：痛点引入→产品核心优势→功能详解→用户价值总结；
2. 语言正式流畅，规避夸大虚假宣传话术；
3. 文案开头提炼3条简短核心slogan；
4. 重点说明产品解决的问题、带给用户实际收益。
版本 2：社交媒体轻量化版（短视频 / 小红书 / 朋友圈）
# 角色
爆款新媒体文案策划，擅长共情种草短文案。
# 已知输入维度
1. 产品名称+品类
2. 产品特色、功能、使用场景
3. 目标用户画像、日常痛点
# 输出要求
1. 产出两套文案：小红书种草、短视频口播；
2. 小红书：情绪开头+痛点共鸣+分点优势+结尾引导+5个热门标签；
3. 短视频：150字内口语文案，开头3句抓眼球；
4. 风格接地气，侧重使用体验提升。
版本 3：广告创意版（海报 / 信息流广告）
# 角色
资深广告创意文案，擅长高转化广告内容。
# 输入信息
产品名称、产品核心卖点、目标受众、投放渠道。
# 输出内容
1. 5组8-15字海报短广告语；
2. 3版100字内信息流文案，分别侧重不同用户痛点；
3. 突出利益冲击，适配公域投放。

基础撰写方法

向 AI 提交需求时，提供三类核心信息，保障文案精准落地：

  1. 产品名称与所属品类
  2. 产品核心功能、差异化特点
  3. 目标用户群体画像

案例 1：电子产品（智能耳机）

你：请帮我写一款智能耳机的产品描述，主要特点包括：降噪功能、长续航、音质出色 claude 回答示例： 【SoundPro 智能降噪耳机】—— 你的私人音乐空间 采用先进的主动降噪技术，有效隔绝外界噪音，让你沉浸在纯净的音乐世界中。无论是通勤路上的嘈杂，还是办公室的纷扰，都能一键屏蔽，只留美好旋律。 超长续航设计，单次充电可连续播放 30 小时，满足你一周的使用需求。 专业级音质调校，40mm 大动圈单元，呈现丰富细腻的音质。无论是流行音乐的节奏感，还是古典音乐的层次感，都能完美呈现。

案例 2：食品产品（有机蔬菜）

你：请帮我写一款有机蔬菜产品描述，强调健康、新鲜、无农药，目标用户是注重健康的家庭主妇 claude 回答示例： 【田园鲜语 有机蔬菜】—— 来自大自然的纯净馈赠 每一颗蔬菜，都承载着我们对健康的承诺。 田园鲜语有机蔬菜，严格遵循有机种植标准，全程不使用化学农药和化肥。从播种到收获，每一个环节都经过精心呵护，确保每一颗蔬菜都纯净无污染。 清晨采摘，冷链运输，从田间到餐桌全程不超过 24 小时。锁住蔬菜新鲜与营养，让你和家人享受到原汁原味的健康美味。

广告文案生成

1. 创意种草广告

你：请帮我写一款智能水杯创意广告，功能：提醒喝水、记录饮水量、温度显示，目标人群上班族 claude 回答示例： 【别让忙碌，偷走你的健康】 你有多久没有好好喝一杯水了？ 工作繁忙，会议不断，一忙就是一整天。等到口干舌燥，才想起许久没喝水。 智能水杯，你的健康小管家。 ✨智能提醒：根据活动状态智能提醒饮水，再忙不会忘记。 📊饮水记录：APP 自动统计饮水量，健康数据清晰可见。 🌡️温度实时显示，避免烫嘴或饮用凉水。 🔋超长续航，单次充电可用 30 天。 工作重要，健康更重要，每天喝够 8 杯水。

2. 促销转化广告

你：写咖啡店周年庆促销广告，全场咖啡买一送一，活动三天 claude 回答示例： 【周年庆狂欢】买一送一，连享三天！ 感谢一年陪伴，门店周年专属活动上线： 全场咖啡买一送一，赠送饮品可堂食或打包。 活动时间：指定三日，不与其他优惠叠加。 额外福利：新品免费试饮、消费满额赠咖啡杯、会员积分双倍。 期待到店打卡，地址 & 营业时间详见门店。

社交媒体内容生成

1. 朋友圈氛围感文案

你：写周末逛书店朋友圈文案，文艺有温度 claude 回答示例： 周末的午后，躲进书店的角落。📚 阳光透过落地窗落在书页，空气中混着书香与咖啡香。放下工作与繁杂信息，安静读几页书，时间都慢了下来。简单的独处，就是最好的治愈。 # 周末时光 #书店 #慢生活 #阅读

2. 小红书种草文案

你：写护手霜小红书种草文案，详细有说服力 claude 回答示例： 【秋冬必备护手霜真的挖到宝藏】🧴 秋冬手部干燥起皮，试过多款终于找到适配款：

  1. 质地轻薄易吸收，涂完不粘手机键盘；
  2. 长效保湿，全天手部水润不起皮；
  3. 添加维 E、神经酰胺，修复粗糙干纹；
  4. 淡香不刺鼻，使用感舒适；
  5. 性价比高，一支耐用。

本人干皮亲测，坚持一周手部明显顺滑。 # 护手霜推荐 #秋冬护肤 #好物分享 #护手

文案创作 6 大核心技巧

  1. 明确目标：先确定销售 / 种草 / 宣传等核心目的，内容不跑偏；
  2. 精准受众：锁定用户年龄、消费痛点，文案精准戳需求；
  3. 聚焦卖点：突出差异化优势，弱化同质化参数；
  4. 情感共鸣：场景化叙事，拉近与用户距离；
  5. 行动号召文末添加下单、到店、收藏等引导话术；
  6. 多版本测试产出多版文案投放，根据数据择优迭代。

【小节小结】文案创作遵循「定目标→抓用户→讲卖点→造共情→促行动」流程，多版本测试可持续提升转化。

4.2 文本润色、改写、摘要、格式转换

一、文本润色

你：润色文字：软件很好用，功能很多，操作也简单 claude 回答示例： 这款软件综合表现优异，内置功能丰富全面，操作界面简洁直观，上手门槛低，无论是日常办公还是专业业务场景都能适配，推荐使用。

二、改写调整

  1. 语气改写

你：把这段话改正式：大家好，今天我们要讲的是怎么用这个软件，很简单，跟着我学就行 claude 回答示例： 各位同仁大家好，本次教程将为大家讲解软件标准操作流程，内容通俗易懂，可按照分步指引逐步学习。

  1. 受众适配改写

你：把这段技术文字改成普通人能看懂的版本：本系统采用分布式架构，支持水平扩展，通过负载均衡实现高可用性 claude 回答示例： 这套系统采用多服务器协同设计，一台设备故障不影响整体使用；用户变多后可直接扩容，全程运行稳定不卡顿。

三、扩写 / 缩写 / 提取摘要

  1. 扩写

你：围绕句子扩写：喜欢旅行，可以看到不同风景 claude 回答示例： 我十分热爱旅行。每一次出行都能去往陌生城市，领略各地特色风光、风土人情；看山川湖海，感受不一样的生活节奏。旅途拓宽眼界，积攒独一无二的人生回忆，是治愈日常疲惫最好的方式。

  1. 缩写

你：精简文字：鉴于当前市场环境的复杂性和不确定性，以及全球经济形势的波动，我们需要采取更加谨慎和稳健的策略来应对可能出现的各种挑战和风险，同时也要抓住潜在的发展机遇 claude 回答示例： 市场与全球经济波动较大，公司需采取稳健策略对冲风险，同时把握发展机遇。

  1. 提取摘要

你：为 AI 教育文章提炼摘要 claude 回答示例： 本文分析人工智能在教育领域应用现状，介绍个性化教学、智能批改等落地模式，同时提出技术伦理、教师转型现存挑战，展望人机协同的未来教育发展方向。

四、格式转换

  1. 文本转有序列表

你：把句子转为列表：提高工作效率的方法包括：制定计划、优先级管理、专注工作、适当休息、利用工具 claude 回答示例： 提高工作效率的方法：

  1. 制定计划
  2. 优先级管理
  3. 专注工作
  4. 适当休息

实战优化案例

案例 1 会议纪要整理

你：把零散记录整理规范：今天开会讨论项目进度，张三说前端完成 80%，李四后端 70%，王五测试没开始，进度可能延期，下周再开会 claude 回答示例：

项目进度会议纪要

会议人员：张三、李四、王五

  1. 进度汇报
  • 前端（张三）：完成 80%
  • 后端（李四）：完成 70%
  • 测试（王五）：尚未启动
  1. 现存问题：整体进度滞后，存在延期风险
  2. 决议事项：下周召开进度跟进会
  3. 待办：各负责人加速开发，测试提前规划

案例 2 产品说明文档优化

你：把口语描述结构化：这个产品有很多功能，比如录音、放音乐、打电话、发短信、上网，电池耐用，屏幕大，操作简单 claude 回答示例：

智能手机产品说明

一、核心功能

  1. 通信：高清通话、短信、语音助手
  2. 多媒体：音乐、高清视频录制
  3. 网络：4G/5G、蓝牙、Wi-Fi

二、产品优势

  • 超长续航：大容量电池，全天使用无压力
  • 大屏全面屏，视觉体验佳
  • 简易交互界面，新手易上手

三、适用人群

商务办公、年轻娱乐、日常通信用户

文本优化 6 大实用技巧

  1. 明确优化目标（精简 / 美化 / 通俗化 / 结构化）；
  2. 告知 AI 使用场景、行业、目标受众；
  3. 提前约定输出格式（段落 / 列表 / 表格 / 公文）；
  4. 初次效果不佳可多次迭代调整；
  5. 修改前备份原始文本；
  6. AI 输出后人工核对信息准确性。

【小节小结】文本润色、改写、格式转换通用逻辑：先明确用途与受众，再指定输出格式，完成后人工校验。

《那年盛夏》

小明和小红是邻居，也是最好的朋友，每日一同上学放学。 一年夏天小明高烧无法上课，小红每天放学后带上漫画，到他家补习功课、陪伴他。 等小明康复，许多知识点落下，小红持续每日为他梳理难点。 小明十分感激，小红却说好朋友本应互相扶持。 多年后两人各自奔赴不同人生，每到盛夏，总会想起那段纯粹温暖的陪伴。友谊如同夏日暖阳，长久照亮生活。

四、短视频脚本创作

你：写 5-8 分钟治愈家常菜短视频脚本，主题外婆红烧肉 claude 回答示例：

《家的味道：外婆的红烧肉》

视频风格：温馨怀旧，时长 5-8 分钟

  1. 开场（30s）

画面：阳光老式厨房；旁白：每个人记忆里都有一道家的味道；轻音乐铺垫。

  1. 食材准备（1min）

画面依次展示五花肉、冰糖、葱姜；特写食材纹理，讲解选材要点。

  1. 烹饪过程（3min）

焯水、炒糖色、小火慢炖；特写冰糖焦化、肉块焖煮画面，讲解核心步骤。

  1. 出锅品尝（1min）

红烧肉盛盘，博主试吃；旁白描述软糯入味的口感。

  1. 结尾（30s）

老照片慢镜头，旁白怀念外婆，音乐缓缓淡出。

创意内容 6 大实用技巧

  1. 补充行业、受众、场景细节，产出更贴合落地；
  2. 提前固定风格（幽默 / 专业 / 治愈）；
  3. 批量多组创意，横向对比择优；
  4. 融合多个方案亮点再造新创意；
  5. 归档优质灵感，同类场景复用；
  6. 不满意多次补充约束条件迭代。

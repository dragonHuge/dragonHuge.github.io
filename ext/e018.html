第四章：文本处理与创作

2026-11-09 · AI与大模型/大模型实战宝典/raw/15-05-第四章：文本处理与创作.md

文案生成是 AI 常用功能，覆盖产品宣传、广告、社交内容等场景，可快速产出高质量文案。

产品描述创作

基本方法

生成产品描述需提供 3 类信息，输出效果更佳：

  • 产品名称和类型
  • 主要功能和特点
  • 目标用户群体

一、原基础提示词

请基于以下信息，为我撰写一份专业的产品宣传描述文案，用于产品推广、广告投放、社交媒体发布：
1. 产品名称与所属品类
2. 产品核心功能、差异化特点、优势亮点
3. 精准的目标用户人群画像
要求文案内容高质量、贴合推广场景，具备吸引力与说服力。

二、优化后多版本提示词

版本 1：专业标准版（电商 / 官网产品详情）
# 角色定位
你是资深产品营销文案师，擅长撰写电商详情、官网产品介绍类文案，语言专业严谨，突出产品价值，精准触达目标用户痛点。
# 输入信息
1. 产品名称+所属行业/产品品类
2. 产品核心功能、核心优势、差异化卖点、使用场景
3. 目标用户群体、用户痛点、用户核心需求
# 输出要求
1. 撰写800字以内产品宣传文案，结构：痛点引入→产品核心优势→功能详解→用户价值总结；
2. 语言正式流畅，规避夸大虚假宣传话术；
3. 文案开头提炼3条简短核心slogan；
4. 重点说明产品解决的问题、带给用户实际收益。
版本 2：社交媒体轻量化版（短视频 / 小红书 / 朋友圈）
# 角色
爆款新媒体文案策划，擅长共情种草短文案。
# 已知输入维度
1. 产品名称+品类
2. 产品特色、功能、使用场景
3. 目标用户画像、日常痛点
# 输出要求
1. 产出两套文案：小红书种草、短视频口播；
2. 小红书：情绪开头+痛点共鸣+分点优势+结尾引导+5个热门标签；
3. 短视频：150字内口语文案，开头3句抓眼球；
4. 风格接地气，侧重使用体验提升。
版本 3：广告创意版（海报 / 信息流广告）
# 角色
资深广告创意文案，擅长高转化广告内容。
# 输入信息
产品名称、产品核心卖点、目标受众、投放渠道。
# 输出内容
1. 5组8-15字海报短广告语；
2. 3版100字内信息流文案，分别侧重不同用户痛点；
3. 突出利益冲击，适配公域投放。

基础撰写方法

向 AI 提交需求时，提供三类核心信息，保障文案精准落地：

  1. 产品名称与所属品类
  2. 产品核心功能、差异化特点
  3. 目标用户群体画像

案例 1：电子产品（智能耳机）

你：请帮我写一款智能耳机的产品描述，主要特点包括：降噪功能、长续航、音质出色 claude 回答示例： 【SoundPro 智能降噪耳机】—— 你的私人音乐空间 采用先进的主动降噪技术，有效隔绝外界噪音，让你沉浸在纯净的音乐世界中。无论是通勤路上的嘈杂，还是办公室的纷扰，都能一键屏蔽，只留美好旋律。 超长续航设计，单次充电可连续播放 30 小时，满足你一周的使用需求。 专业级音质调校，40mm 大动圈单元，呈现丰富细腻的音质。无论是流行音乐的节奏感，还是古典音乐的层次感，都能完美呈现。

案例 2：食品产品（有机蔬菜）

你：请帮我写一款有机蔬菜产品描述，强调健康、新鲜、无农药，目标用户是注重健康的家庭主妇 claude 回答示例： 【田园鲜语 有机蔬菜】—— 来自大自然的纯净馈赠 每一颗蔬菜，都承载着我们对健康的承诺。 田园鲜语有机蔬菜，严格遵循有机种植标准，全程不使用化学农药和化肥。从播种到收获，每一个环节都经过精心呵护，确保每一颗蔬菜都纯净无污染。 清晨采摘，冷链运输，从田间到餐桌全程不超过 24 小时。锁住蔬菜新鲜与营养，让你和家人享受到原汁原味的健康美味。

广告文案生成

1. 创意种草广告

你：请帮我写一款智能水杯创意广告，功能：提醒喝水、记录饮水量、温度显示，目标人群上班族 claude 回答示例： 【别让忙碌，偷走你的健康】 你有多久没有好好喝一杯水了？ 工作繁忙，会议不断，一忙就是一整天。等到口干舌燥，才想起许久没喝水。 智能水杯，你的健康小管家。 ✨智能提醒：根据活动状态智能提醒饮水，再忙不会忘记。 📊饮水记录：APP 自动统计饮水量，健康数据清晰可见。 🌡️温度实时显示，避免烫嘴或饮用凉水。 🔋超长续航，单次充电可用 30 天。 工作重要，健康更重要，每天喝够 8 杯水。

2. 促销转化广告

你：写咖啡店周年庆促销广告，全场咖啡买一送一，活动三天 claude 回答示例： 【周年庆狂欢】买一送一，连享三天！ 感谢一年陪伴，门店周年专属活动上线： 全场咖啡买一送一，赠送饮品可堂食或打包。 活动时间：指定三日，不与其他优惠叠加。 额外福利：新品免费试饮、消费满额赠咖啡杯、会员积分双倍。 期待到店打卡，地址 & 营业时间详见门店。

社交媒体内容生成

1. 朋友圈氛围感文案

FID：小米设备不变的硬件标识

2026-09-30 · 文字记录 · 工具与技术/20260930-FID设备不变的硬件标识.md

来源：文字记录 归档日期：2026-09-30 抓取状态：成功 原文字符：706｜配图：0 张

摘要速览

  • FID 来自小米手机 provision 时生成的 DH 值：对固定字符串用 KDF 计算，原始密钥取自 CPU 和其它设备硬件配件 ID 的固定值（get_dh，高通平台）
  • 变化规则：更换 CPU 或某些硬件配件会变；无硬件变化时，系统重置、各种刷机、IMEI 改写均不变
  • 收集方式：授权客户端 App 调用 tzapp，提供被签名内容，返回 fid+签名用于设备验证；单独 fid 可作设备不变硬件 ID
  • 业务诉求（MicloudFind）：识别物理设备，既不能被刷机/软件篡改抹除身份，也不能被伪造接口/录制重放模拟他人身份
  • 常用于：手机查找、手机 provision 过程、手机签名和验签

核心内容

FID 是小米生态的设备级根标识：硬件指纹（CPU+配件 ID）经 KDF 派生，天然绑定物理设备而非软件状态。这使它同时满足两个安全目标——抗抹除（刷机、重置、改 IMEI 都无法清除）与抗伪造（配合签名验证，接口伪造、录制重放无法冒充）。tzapp 的「内容签名 → fid+签名」返回模式，把设备身份验证做成系统级能力，业务方无需自行采集硬件信息。

可执行启发

  • 做设备风控/账号安全时，优先用系统级硬件标识（如 fid+签名）而非软件层可篡改 ID
  • 设备绑定类业务（查找、支付、provision）应把关键操作与设备身份验证绑定
  • 芯片厂商/版本间 FID 格式不同，跨端比对需注意格式差异，不做格式假设

FID

什么是FID

fid来自小米手机provision时生成的DH值。其生成方法是：对一个固定的字符串用KDF计算创建，原始密钥为读取自CPU和其它设备硬件配件ID的某些固定值。

来源代码 - get_dh()（高通平台） （注，不用关心FID格式，这个每个芯片厂商是不同的，甚至芯片版本也不同）

MicloudFind业务依赖于设备验证来识别一台物理设备，既不能使用刷机、软件篡改等抹除自己的身份，也不能使用伪造接口数据、录制重放等手段来模拟别人的身份。因此业务需要一个不变的设备标识，并在某些关键操作上能绑定了对设备的身份验证。

FID会变吗？

根据fid计算生产的规则，如果更换cpu，或某些其它硬件配件，fid会发生变化。 如果没有硬件变化，那么fid在系统重置、各种刷机、IMEI改写的情况下都不会变。

FID怎么收集，使用的

客户端App，如果被授权，可以调用tzapp，提供一段被签名内容，返回得到：fid+签名。fid+签名 用于设备验证。单独的fid可以用于作为设备不变的硬件ID。

FID作为这个不变的设备标识，目前常用于：1） 手机查找 2）手机provision过程 3）手机签名和验签

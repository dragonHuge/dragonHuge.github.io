摘要速览

  • 双层架构：首层 Model Armor 秒级过滤（约拦 85% 违规），边缘转二层 Gemini 4 视觉复核
  • 实测基准：文本端到端 100ms、多模态图片 700ms、单图上限 4MiB（OCR+视觉并行）
  • Model Armor 统一网关：sanitizeUserPrompt/Response、五过滤器并行、SDP 脱敏、Safe Browsing
  • 图片审核双路径：OCR 字符级+像素坐标框（可打码留痕）与视觉分类（IMAGE_TYPE InfoType）
  • 工程铁律：前置转码+4MiB 限流、Fail-Closed 状态机——不可仅凭 HTTP 200 放行
  • 落地页三段式治理：Safe Browsing→Cloud Run 无头浏览器正文→首屏截图 OCR 复核
  • 中文敏感词：SDP 自定义正则+De-id 自动脱敏，突破词典分词连续中文漏报
  • 附录：Gemini 4.0 Argon GA（1M Input+1M Output、单任务约 $1.99）与 Antigravity 2.0

核心内容

面向企业内容安全的双层纵深方案：把「确定性规则的低延迟」与「大模型推理的上下文理解」分工——首层 Model Armor API 以单次调用并行执行五大内置检测器与敏感数据保护完成高速基线过滤与脱敏，首层拦截约 85% 违规；仅 POSSIBLE 及可疑样本升级二层 Gemini 4 视觉复核（temperature=0、输出结构化 JSON 判罚理由）对接 SOC。图片侧走 OCR+视觉双路径并以坐标框支撑精准打码；落地页用三段式流水线封堵「正文干净、违规词绘入海报」的图文分离黑产页；跨区域合规以 SDP 自定义正则+De-id 在送模型前完成脱敏。全篇以大量实测值（延迟、召回、成本权衡矩阵）给出按业务场景的分级路由与 90 天三阶段实施路线图。

可执行启发

  • 拦截链路按置信度分级：固定黑名单走本地前缀树（<50ms），常规走首层，可疑才升级大模型复核
  • 送审前置统一转码与限流，状态机 Fail-Closed，杜绝「返 200 即安全」的静默跳过陷阱
  • 中文敏感词改用自定义正则+自动脱敏占位符，绕开词典按空格分词的连续中文漏报
  • 图片返回违规字像素边界框，可直接用于打码与审计留痕，是图文审核落地的关键工程细节

Package

Java

<dependency>
    <groupId>com.公司.infosec.risk</groupId>

    <version>1.0.4</version>          // 使用最新版

Thrift定义

namespace java com.公司.infosec.risk.taglist
namespace go infosec.risk.taglist

exception ListServiceException {
    1: required i32 code;
    2: required string msg;
}

struct ListItem { // 名单
    1: required string objType; // 名单类型
    2: required string objValue; // 名单值
    3: required list<TagItem> tags;
    4: optional string extra;
}

struct TagItem { // 标签
    1: required i32 tagId;
    2: required i64 expired; // 标签过期时间，秒级时间戳
    3: required i64 updated; // 标签添加时间，毫秒级时间戳
}

service ListService {
    ListItem queryTags(
        1: required string objType,
        2: required string objValue,
        3: optional list<i32> tags;
        4: optional i64 expired;
    ) throws (1: ListServiceException e)

    ListItem queryTagsWithParent(
            1: required string objType,
            2: required string objValue,
            3: optional list<i32> tags;
            4: optional i64 expired;
        ) throws (1: ListServiceException e)

    bool addTags(
        1: required string objType,
        2: required string objValue,
        3: required list<TagItem> tags;
        4: required string reason;
        5: required string operator;
        6: optional string source;
        7: optional string extra;
    ) throws (1: ListServiceException e)

    // 支持分页查询逻辑。
    list<ListItem> getAllTagItemsByTagId(
        1: required i32 tagId,
        2: optional i32 pageNum, 
        3: optional i32 pageSize,

    ) throws (1: ListServiceException e)


}

接口详解

getAllTagItemsByTagId

  • 含义：根据标签Id，查出此标签下的所有名单。支持分页查询。

  • 参数

    类型

    必有字段

    含义

    tagId

    i32

    required

    标签ID - 由风控侧定义

    pageNum

    i32

    optional

    支持分页查询。

    • 分页逻辑：根据标签ID筛出名单，根据名单更新时间倒序排列，再进行分页。

    • 当(pageNum=0 | pageSize=0) 时，默认查询最新10000个名单，即(pageNum=1 & pageSize=10000)

    示例：

    • 查第1页，每页200条名单 -> pageNum=1,pageSize=200。
    • 走默认查询 -> pageNum、pageSize两者其一为0即可。

    pageSize

    i32

    optional

  • 参数

    含义

    list<ListItem>

    名单列表。返回打上tagId标签的所有名单。

  • // 入参：
ListService.Iface client = createClient();
List<ListItem> items = client.getAllTagItemsByTagId(200002, 0, 0);

// 出参（items）：
ListItem{objType=ip, objValue=1.1.1.2, tags=[TagItem{tagId=200002, expired=1753928065, updated=1752027296000}], extra={"wms_sid":["wms1","wms2"]}}
ListItem{objType=ip, objValue=1.1.1.1, tags=[TagItem{tagId=200002, expired=1753964470, updated=1752027060000}], extra={"wms_sid":["wms-pro","wms_pro","wms_pre_ru"]}}

queryTags

  • tags为空列表 ： 未命中传入的标签或其子标签。
  • tags为非空列表 ： 非空列表中的tags即为名单命中的标签。

  • 参数

    类型

    必有字段

    含义

    objType

    string

    required

    名单类型，如：用户ID、ip、email、

    objValue

    string

    required

    名单值，如：123456,1.1.1.1

    tags

    list<i32>

    required

    标签列表，

    expired

    string

    required

    过期时间，秒级绝对时间戳。

  • 参数

    含义

    ListItem

    名单实体类，其中tags字段包含该名单下未过期的所有标签/子标签。

  • // 入参：
ListService.Iface client = createClient();
List<Integer> tagIds = Arrays.stream(tagStr.split(","))
        .map(Integer::parseInt)
        .collect(Collectors.toList());

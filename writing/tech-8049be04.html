技术选型

整体使用：Vue + Ant Design Pro

教程网站：https://pro.antdv.com/docs/getting-started

🤨 项目启动注意事项：

  1. 首先需安装版本≥18的node

可以使用nvm进行node管理，nvm use 命令切换到对应版本即可

  1. 安装yarn：

```Shell npm install -g yarn ```

  1. 启动项目：

yarn install

yarn run serve

前端规范

根据多词规则规范，前端编程时，注意以下几点：

  1. 组件vue文件的命名方式：PascalCase（大驼峰命名法）

即首字母大写，每个单词的首字母也大写。例如，UserProfile、LoginForm。

  1. 模板中引用组件时：用' - '作多词分隔
  1. 注册组件时：多词大驼峰命名。

示例：

<template>
  <user-profile></user-profile>
</template>
<script>
import UserProfile from './components/UserProfile.vue';
export default {
  components: {
    UserProfile,  // 多词组件名称
  },
};
</script>

1.多词规则

在 Vue.js 中，多词规则（Multi-word Component Names）是指组件的名称应该由两个或更多的单词组成。

这个规则是 Vue 的一个最佳实践，旨在避免与现有的 HTML 标签名称冲突，并提高代码的可读性。

以下是多词规则的一些要点：

  1. 避免冲突：由于 Vue 组件可以通过自定义元素的方式在 HTML 中使用，使用多词名称可以避免与 HTML 的标准标签（如 &lt;a&gt;、&lt;button&gt; 等）发生冲突。
  1. 提高可读性：多词名称可以更清晰地表达组件的功能或用途，使得代码更加易于理解和维护。
  1. 遵循 PascalCase 命名：在 Vue 中，通常使用 PascalCase（大驼峰命名法）来命名组件，即首字母大写，每个单词的首字母也大写。例如，UserProfile、LoginForm。
  1. 文件命名：组件的文件名也应该遵循多词规则，与组件的名称相对应。例如，UserProfile.vue、LoginForm.vue。
  1. 模板中使用：在模板中引用组件时，也应该使用多词名称，即用'-分隔'。例如：

```Vue <template> <user-profile></user-profile> </template> ```

  1. JavaScript 中注册：在 JavaScript 中注册组件时，无论是局部注册还是全局注册，都应该使用多词名称。例如：

```Java <script> import UserProfile from './components/UserProfile.vue'; export default { components: { UserProfile, // 多词组件名称 }, }; </script> ```

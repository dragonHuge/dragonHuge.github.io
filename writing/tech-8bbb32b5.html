常用工具解释(node/nvm/vue)

2024-08-15 · 飞书原文 ↗

node、npm、nvm

🤯 Node.js：JavaScript 运行时环境，允许开发者在服务器端运行 JavaScript 代码。

Npm：一个 JavaScript 包管理器，用于管理 Node.js 应用程序的依赖。

Nvm：用于管理多个 Node.js 版本。它允许你在同一台机器上安装和切换不同的 Node.js 版本。

nvm简单使用：

  1. 查看nvm支持安装的node版本

```XML nvm list available ```

  1. 安装指定版本

```Shell nvm install 14.17.5 # 安装14.17.5版本 ```

  1. 使用指定版本的node(管理员权限打开命令行)

```Shell nvm use 14.17.5 ```

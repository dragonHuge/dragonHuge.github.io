public Integer getStringTypeCount(String key) {

    return redisTemplate.hasKey(key) ?
            Integer.parseInt(redisTemplate.opsForValue().get(key).toString()) : 0;

}

public Integer getZSetTypeCount(String key, Long timeSpan) {
    int count = 0;
    long nowTs = System.currentTimeMillis() / 1000;
    if (redisTemplate.hasKey(key)) {
        Set set = redisTemplate.opsForZSet().rangeByScore(key, nowTs - timeSpan, nowTs); // 获取指定时间范围内的数据
        count = CollectionUtils.isNotEmpty(set) ? Integer.parseInt(set.iterator().next().toString()) : count;
    }
    return count;
}

    二期：IP信誉库规则引擎启用

    IP信誉库的规则引擎依据数据来自Redis，而此Redis的数据来自各方talos，由实时任务完成同步。

    当前这套IP信誉库成本有些高。若需重启，大概有以下工作：

    1. 所有实时任务重启&逻辑梳理。
    1. 爬虫平台两数据源->talos的数据格式化。
    1. 永安数据拉取定时任务重启。
    1. 各数据源的溯源与可用性评估。
    1. 规则引擎逻辑细节剖析。

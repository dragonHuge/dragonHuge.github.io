Spring Boot 启动规则

2026-07-09"本地沉淀 · 风控工程知识库"

本文是工程规则（团队约定 + 踩坑结论），不是入门教程： 适合「已经知道要做什么，只想知道怎么做才不出事」的场景。

1. 适用范围

风控在线服务（apus thrift RPC 服务）启动层。不覆盖 web/MVC、不覆盖 Spring Security、不覆盖响应式 webflux。

新风控服务的 Spring Boot 启动 + KeyCenter 初始化 + 多 region profile + appassembler 打包 全部走本文。

2. 版本 / 依赖

坐标版本备注
org.springframework.boot:spring-boot-starter-parent由公司 parent-pom 锁定不要在子项目里覆盖
com.公司.mit:mit-starter跟随 parent-pom公司链路追踪 / 治理 starter
org.springframework.boot:spring-boot-starter-test由 BOM 锁定测试 scope
org.springframework.boot:spring-boot-starter-web不引风控服务为 non-web；走 apus thrift
com.alibaba.boot:nacos-config-spring-boot-starter由根 pom 锁定配置中心，见 nacos.md

关键属性（继承自公司 parent）：

  • Java 21 主线（spark module 退回 Java 8）
  • spring.main.web-application-type=none（不起 web 容器）
  • maven resource filtering delimiters：${*} + @（详见 §6.2）

3. 标准骨架

3.1 启动类（main 只 SpringApplication.run）

package ${basePackage};

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class ${serviceApplicationClass} {

    static {
        System.setProperty("logging.config", "classpath:logback-spring.xml");
    }

    public static void main(String[] args) {
        SpringApplication.run(${serviceApplicationClass}.class, args);
    }
}

铁律：

  • main 中不自行启动 RPC server / Talos producer / 其他外设 — 全部走 @Bean + ApplicationRunner
  • logging.config 在 static block 里设，早于 Spring 启动
  • 想用调度 / Plan 等公司 starter，在类上加注解（如 @EnableMiPlan），不要在 main 里调

3.2 application.yml 最小骨架

spring:
  main:
    web-application-type: none
env: ${env}
apus:
  port: ${apusPort}
nacos:
  config:
    bootstrap:
      enable: true
    remote-first: true
    server-addr: ${config.nacos.host}
    namespace: ${config.nacos.namespace}
    username: ${config.nacos.username}
    password: ${config.nacos.password}
    data-ids: ${config.nacos.data-ids}
    auto-refresh: true
    group: ${config.nacos.group}
    type: yaml
    max-retry: 3
    config-retry-time: 2000
    config-long-poll-timeout: 30000
    enable-remote-sync-config: true
zookeeper:
  default: ${zookeeper.host}
  host:
    staging: staging
    # region key → ZK env value，由 ${apusServerClass} 在 resolveZkEnv 读取

完整 nacos 段说明见 nacos.md §3.2。

3.3 BeanConfiguration 装配模式

@Configuration
public class BeanConfiguration {

    @Value("${redis.${configPrefix}.host}")
    private String redisHost;

    private JedisPooled jedisPooled;
    private ${producerClass} producer;

    @PostConstruct
    public void init() {
        this.jedisPooled = JedisFactory.createJedisPooled(redisHost, ...);
        this.producer = new ${producerClass}(...);
        this.producer.init();
    }

    @PreDestroy
    public void destroy() {
        if (producer != null) producer.shutdown();
    }

    @Bean public JedisPooled jedisPooled() { return jedisPooled; }
    @Bean public ${producerClass} producer() { return producer; }
    // 其他 RPC impl / server Bean ...
}

铁律：

  • 外部资源（Redis / Talos producer）用 @PostConstruct init + @PreDestroy destroy
  • 不要在 @Bean 方法里 new 大对象后又当字段持有 — 二选一
  • 同步阻塞，不引 spring-data-redis / Lettuce / WebFlux

3.4 appassembler 打包（service 模块）

service/pom.xml：

<plugin>
    <groupId>org.codehaus.mojo</groupId>
    <artifactId>appassembler-maven-plugin</artifactId>
    <version>2.1.0</version>
    <configuration>
        <programs>
            <program>
                <mainClass>${basePackage}.${serviceApplicationClass}</mainClass>
                <id>run.sh</id>
                <platforms><platform>unix</platform></platforms>
            </program>
        </programs>
        <repositoryLayout>flat</repositoryLayout>
        <assembleDirectory>release</assembleDirectory>
        <configurationSourceDirectory>src/main/resources</configurationSourceDirectory>
        <configurationDirectory>configuration</configurationDirectory>
        <copyConfigurationDirectory>true</copyConfigurationDirectory>
        <includeConfigurationDirectoryInClasspath>true</includeConfigurationDirectoryInClasspath>
        <filterConfigurationDirectory>true</filterConfigurationDirectory>
        <repositoryName>lib</repositoryName>
        <extraJvmArguments>
            -XX:InitialRAMPercentage=60.0
            -XX:MaxRAMPercentage=60.0
            -Xss512k
            -XX:+UseG1GC
            -XX:MaxGCPauseMillis=200
            -XX:+ParallelRefProcEnabled
            -XX:+UseStringDeduplication
            -XX:+HeapDumpOnOutOfMemoryError
            -XX:HeapDumpPath=/home/work/logs
            -XX:+ExitOnOutOfMemoryError
            -XX:+UseGCLogFileRotation
            -XX:NumberOfGCLogFiles=10
            -XX:GCLogFileSize=100M
            -Xloggc:/home/work/logs/gc.log
        </extraJvmArguments>
    </configuration>
    <executions>
        <execution>
            <phase>package</phase>
            <goals><goal>assemble</goal></goals>
        </execution>
    </executions>
</plugin>

产出 release/{bin,configuration,lib}/，bin 内含可执行 run.sh。

4. 配置项

配置 key默认说明
spring.main.web-application-typenone风控服务不起 web
env由 maven profile 注入staging/prod/sgp/ind/rus/eur 之一
${apusPort} 字面由使用方提供apus 监听端口
zookeeper.default由 profile 注入默认 ZK env 名
zookeeper.host.*静态映射region → ZK env 名映射
logging.configclasspath:logback-spring.xml必须用 logback-spring.xml（支持 spring profile）

5. 监控与日志

  • PerfCounter 启动指标：
    • ${metricPrefix}.startup.apus_started — apus 启动成功
    • ${metricPrefix}.startup.apus_failed — apus 启动失败
    • ${metricPrefix}.startup.zk_env_missing — ZK env 未解析到
  • logback-spring.xml 必须在 src/main/resources，文件名固定（spring 才能注入 profile）
  • 容器化 GC 日志固定写 /home/work/logs/gc.log（appassembler 配置见 §3.4）

6. 常见踩坑

6.1 🔴 main 里直接启动外设

错误：main() 里手写 new TalosProducer(...).init()。 后果：Spring 还没装配完就跑业务初始化，依赖注入失效。 正确：用 @PostConstruct 或 ApplicationRunner。

6.2 🔴 resource filtering delimiter 配置丢失

maven 默认占位符是 ${*}，但 Spring 也用 ${*} 做 placeholder。必须在根 pom 配 &lt;delimiters&gt; 加 @ 作为 maven-only 占位（如 @profiles.active@），让 maven 编译期替换的归 maven、运行期替换的归 Spring。

<plugin>
    <artifactId>maven-resources-plugin</artifactId>
    <configuration>
        <delimiters>
            <delimiter>${*}</delimiter>
            <delimiter>@</delimiter>
        </delimiters>
        <useDefaultDelimiters>false</useDefaultDelimiters>
    </configuration>
</plugin>

6.3 🟠 logging.config 不在 static block 设

后果：Spring 启动早期日志走默认配置，看不到自定义 layout。 正确：static block 是最早执行点。

6.4 🟠 web-application-type 未设 none

后果：服务起了 tomcat 占端口，但本服务走 apus thrift，端口冲突 / 健康检查混乱。 正确：yml 显式 none。

6.5 🟢 多 region maven profile 漏配某 region

后果：发布该 region 时缺 ${env} / ${zookeeper.host}，启动 NPE。 正确：所有 region profile 字段对齐，CI 校验。

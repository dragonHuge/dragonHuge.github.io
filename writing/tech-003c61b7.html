常见面试题（Java并发）

2024-05-07 · 飞书原文 ↗

1.i++是否线程安全，如何保证安全？

在 Java 中，i++ 操作不是线程安全的，因为它包含了读取变量的当前值、对其进行递增、写入新值这三个步骤，而这些步骤之间并没有原子性保证，即使看起来是一个简单的操作，但在多线程环境下，可能会出现竞态条件（Race Condition）。

要保证 i++ 操作的线程安全，可以采用以下几种方式：

  1. 使用同步机制：可以使用 synchronized 关键字或者 Lock 接口来对 i++ 操作进行同步，确保在同一时刻只有一个线程能够执行该操作，从而避免竞态条件。

```Java synchronized (this) { i++; } ```

  1. 使用原子类：Java 提供了一些原子类，例如 AtomicInteger，它们提供了一些原子操作，可以保证操作的原子性，从而避免竞态条件。

```Java AtomicInteger atomicI = new AtomicInteger(0); atomicI.incrementAndGet(); ```

  1. 使用并发工具：Java 中的并发工具类，如 AtomicLong，也可以保证对变量的原子操作，可以根据具体场景选择合适的工具类来保证线程安全。
  1. 使用volatile关键字：虽然 volatile 关键字不能保证复合操作的原子性，但是它可以保证变量的可见性，这在某些场景下也能够避免一些问题。但需要注意，volatile 不能保证复合操作的原子性，所以在多线程环境下依然不安全。

综上所述，要保证 i++ 操作的线程安全，可以使用同步机制、原子类、并发工具或者 volatile 关键字来保证。选择合适的方式取决于具体的需求和性能要求。

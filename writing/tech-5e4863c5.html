Vue3路由

2024-08-16 · 飞书原文 ↗

在 Vue 3 中，路由跳转通常使用 Vue Router，这是一个官方的路由管理器，用于构建单页面应用程序。Vue Router 3 与 Vue 3 兼容，并且提供了一些新的特性和改进。以下是在 Vue 3 中使用 Vue Router 进行路由跳转的基本步骤：

  1. 安装 Vue Router： 如果你还没有安装 Vue Router，可以通过 npm 或 yarn 来安装它：

```Java npm install vue-router@4 ```

  1. 创建路由实例： 在项目中创建一个路由配置文件，通常是 router/index.js 或 router/index.ts，然后创建一个路由实例：

```Java

import { createRouter, createWebHistory } from 'vue-router'; import HomePage from '../views/HomePage.vue'; import AboutPage from '../views/AboutPage.vue';

const routes = [ { path: '/', name: 'Home', component: HomePage, }, { path: '/about', name: 'About', component: AboutPage, }, // ...其他路由配置 ];

const router = createRouter({ history: createWebHistory(process.env.BASE_URL), routes, });

export default router; ```

  1. 在 Vue 应用中使用路由： 在 main.js 或 main.ts 中引入并使用路由实例：

```Java import { createApp } from 'vue'; import App from './App.vue'; import router from './router';

const app = createApp(App); app.use(router); app.mount('#app'); ```

  1. 在组件中进行路由跳转： 你可以使用 router-link 组件在模板中创建链接，或者使用 router.push 方法在 JavaScript 中进行编程式导航：
  • 使用 &lt;router-link&gt;：

```Java <template> <router-link to="/about">About</router-link> </template> ```

  • 使用 router.push：一般

```Java this.$router.push('/about'); ```

  1. 命名视图和参数传递： 你还可以使用命名视图和传递参数：

```Java // 命名视图 this.$router.push({ name: 'user', params: { userId: 123 } });

// 传递查询参数 this.$router.push({ path: '/search', query: { keyword: 'vue' } }); ```

  1. 监听路由变化： 你可以使用 watch 或 beforeRouteUpdate 生命周期钩子来监听路由变化：

```Java

watch: { '$route'(to, from) { // 路由变化时执行的代码 } } ```

  1. 导航守卫： Vue Router 还提供了导航守卫，允许你在路由跳转前后执行代码：

```Java

router.beforeEach((to, from, next) => { // 路由跳转前执行的代码 next(); }); ```

这些是 Vue 3 中使用 Vue Router 进行路由跳转的基本方法。根据你的具体需求，你可能还需要配置更复杂的路由逻辑和守卫。

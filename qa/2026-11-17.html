1. ACP 是什么？第三个（AGNTCY）市面上常见实现有哪些？

问题原文

① acp 是什么（22:23）② 第三者，市面上常见的有哪些实现呢？（22:34，接上题「ACP 三个意思」中第三个）

答案要点

ACP 常见三个含义——① Agent Client Protocol（Zed 发起，最常用）：编码 Agent 与编辑器/客户端走 JSON-RPC over stdio，一个 Agent 接入即可被 Zed、Neovim 等任意客户端调用，类比 LSP；② Agent Communication Protocol（IBM/BeeAI 捐给 Linux 基金会）：Agent 互操作，已被 Google A2A 吸收；③ Agent Context Protocol（AGNTCY/Cisco）：多 Agent 协作的上下文与任务状态共享。第三方实现生态：客户端侧 Zed 官方首发，Neovim（CodeCompanion/avante.nvim 等）、Emacs agent-shell、JetBrains、VS Code 扩展、Chrome 扩展、Obsidian 插件；Agent 侧 Claude Code、Codex CLI、Gemini CLI、Cursor、Copilot、Goose、Cline、OpenCode、Hermes Agent、OpenClaw 等均在官方清单；SDK 有官方 Python/Rust/TS/Kotlin/Java 及社区 Go/Dart/C# 等；配套官方 ACP Registry 一键安装。若指第三个（AGNTCY 的 Agent Context Protocol）则几乎无独立实现，概念已被 A2A 吸收。

2. SSRF、XSS 是什么？SSRF 怎么攻击、前提是什么、有哪些真实场景？

问题原文

① ssrf，xss 都是什么意思？（22:34，22:46 重发）② ssrf 没懂，举个例子（22:54）③ 那他是怎么攻击的呢？……前提是必须网站里提供这种口子……他最根本是在欺骗，对吧？（22:56）④ 这个能力具体能落实到什么场景呢？我想不出来什么需求场景会有这个能力（23:00）

答案要点

XSS（跨站脚本）= 攻击者把恶意 JS 注入你信任的页面执行，分存储型/反射型/DOM 型，危害是盗 Cookie、冒充操作、蠕虫传播；防法：输入转义、输出编码、CSP、HttpOnly、富文本白名单。SSRF（服务端请求伪造）= 攻击者让服务器替他发请求，借服务器内网身份访问本够不到的地方；例子：「输入网址帮你抓标题」的功能被填入 http://127.0.0.1:8080/admin 或 http://192.168.1.1/，甚至 169.254.169.254 云元数据接口拿 AK/SK。攻击前提确认：网站必须有「收用户 URL → 服务端去取」的口子；本质不是骗内网服务（它收到的是真请求），而是欺骗整个信任链——骗外层网站「这是正常请求」+ 借用服务器的网络位置与内网身份。一句话：SSRF = 把服务端变成你的代理去打本来碰不到的内网。常见场景（需求侧非常普遍）：内容抓取（剪藏、RSS、竞品价格监控）、富媒体处理（生成 OG 分享卡片、图片转存、网页转 PDF）、开发者工具（Webhook 测试、死链检测、短链 302 跳转）、AI（联网搜索抓网页、RAG 导入 URL 文档）、企业内部（SSO/OAuth 回调、CI/CD 拉仓库）。共同点：「目标在用户手里、处理在服务器侧更方便」，只要用户可控地址 + 服务端发起请求同时成立，SSRF 面就存在。防御：URL 白名单、禁内网/回环/元数据地址（含 DNS Rebinding 校验）、限制跳转跟随、出网统一走代理、云上强制 IMDSv2。

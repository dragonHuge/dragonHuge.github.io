22:30 dev-browser 和 web-access 的区别

两个浏览器相关的 Skill，定位完全不同：

web-access = 用我自己的 Chrome 上网

  • 连接日常 Chrome，天然带登录态
  • 通过 curl 调 CDP Proxy API 操控浏览器
  • 能搜索（WebSearch）、能反反爬、能处理小红书/微信等平台
  • 还有子 Agent 并行调研、站点经验积累等能力
  • 日常联网操作首选

dev-browser = 开一个干净的独立 Chromium 写自动化脚本

  • 启动全新 Chromium，没有登录态
  • 通过 Playwright API 写 JS 脚本执行
  • 适合批量操作、可重复的自动化流程、本地开发测试
  • 也支持 Extension 模式连已有 Chrome（但主要场景是独立浏览器）

选择原则：

  • 需要登录态 / 反爬平台 / 搜索信息 → web-access
  • 需要写可复用自动化脚本 / 批量抓取公开数据 / 测试 → dev-browser
  • 两个互补，不冲突
